Website API Integration

Connect your website to this panel like Pterodactyl's Application API. Generate a key below, then have your checkout system call these endpoints with header:
Authorization: Bearer <your-api-key>

Base URL: http://{{ public_host }}:{{ panel_port }}/api/v1
GET /nodes — list your machines & capacity
GET /vps — list all VPS
GET /vps/{id} — get one VPS
POST /vps — create a VPS (called right after checkout)
POST /vps/{id}/suspend — stop a VPS (e.g. non-payment)
POST /vps/{id}/unsuspend — restart a VPS
POST /vps/{id}/renew — extend renewal date
DELETE /vps/{id} — permanently remove
